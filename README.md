# Rap-Battle Helper: rhyme desk

### Meeting Notes

The rhyme helper now accepts a seed word and checks a short set of practice lines. It looks up dictionary rhymes, keeps words found in a small local word bank and lists their syllable counts. Two short functions handle word counting and line analysis. Each practice line receives a visible word-by-word breakdown, a total and a comparison with the chosen syllable target. The program also compares the ending sounds of paired lines. For the supplied light example, it returns twelve rhyme suggestions and counts eight syllables in each line. Results are saved as a readable session and a tab-separated word list. The lines are supplied examples, not generated verses. Corpus selection and Markov-based line generation remain the next steps towards the A1 proposal.


The script asks for a seed word and a syllable target. Press Enter at each prompt for `light` and `8`. Enter one English word and a positive whole-number target. To compare another seed, run again and enter `flow` at the first prompt. Changing the seed changes the suggestions; it does not rewrite the practice lines.

### Setup

```bash
python3 -m venv .venv

```


### Which files matter?

- `rhyme_desk.py` contains the two helper functions and the session steps.
- `wordbank/words.txt` limits the suggestions to a small, readable vocabulary.
- `wordbank/practice.txt` holds one practice line per row.
- `Sessions/session.txt` records the last run, including each word's syllable count.
- `Sessions/rhymes.tsv` stores the suggestions and counts in two tab-separated columns.
- `meeting_note.txt` repeats the progress paragraph for easy reference.

Each run replaces the two files in `Sessions`. The included results use `light` and a target of eight syllables. Add vocabulary to `words.txt` or edit the practice lines to explore further.

### How does the code decide?

`count_syllables()` retrieves a word's pronunciations and counts the syllables in the first listed one. A missing word returns `None`.

`check_line()` extracts English words, retains their order and adds their counts. Unknown words appear as `?`, and the total remains unresolved. This prevents a missing word from silently counting as zero. A difference of `+0` means the estimated total equals the selected target.

The rhyme search intersects the library's results with the local word bank. `max_word_syllables = 2` limits the suggestions using the same first-pronunciation count. The ending check compares the rhyming parts of the first pronunciations of each pair's final words. An unpaired final line still gets a syllable check.

### Where does the text come from?

The vocabulary and two practice lines are retained from the supplied progress ZIP. Its documentation identifies the lines as AI-assisted demonstration text. They are input examples, not published lyrics or output generated by this program. The vocabulary is a small selection of words, not a training corpus. Pronouncing provides access to CMU dictionary pronunciations.

### What is still unfinished?

This simpler version uses the first dictionary pronunciation instead of combining alternative syllable totals. Accent, slang and performance can change the actual count. A rhyme suggestion is a sound match, not a guarantee of meaning or quality, and syllable totals alone do not establish rhythm.

The next stage is to select and document a suitable public-domain corpus, introduce Markov generation and filter candidate lines by rhyme and length. There is no trained model, verse generator or runtime LLM in this version. The final A2 video, personal reflection and public repository are not included.
